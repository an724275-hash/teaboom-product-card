# Карточка товара Teaboom

Тестовое задание на HTML/CSS/JavaScript: верхняя часть карточки «Ананасовый улун».

## Посмотреть

Публичная страница: https://an724275-hash.github.io/teaboom-product-card/

## Запуск

Откройте `index.html` в браузере. Сборка, npm и установка зависимостей не нужны.

Для запуска через локальный сервер из папки проекта:

```sh
python -m http.server 8051
```

Затем откройте http://localhost:8051.

## Что сделано

- Четыре фасовки: 100, 500, 1000 и 5000 г. При выборе синхронно обновляются цена, цена без скидки и артикул.
- Нативные radio-кнопки: выбор работает мышью, касанием и клавиатурой. Цена объявляется через `aria-live`.
- Кнопка «В корзину» со состояниями hover, active и focus. Нажатие показывает выбранную фасовку; запросов к настоящей корзине нет.
- Сетка на CSS Grid: две колонки на планшете и ПК, одна на телефоне. Сохраняются доступность масштабирования и видимый фокус.
- Все изображения и Open Sans загружаются локально. Сайт не использует CDN, аналитику, backend или frontend-фреймворк.

## Структура

```text
index.html      семантическая разметка
styles.css      стили и адаптация
script.js       фасовки и демонстрация кнопки
assets/         товарное фото, логотип и шрифты
```

Без JavaScript показана фасовка 100 г; переключатели и кнопка отключены, чтобы не показывать несогласованные данные.

## Оформление и проверка

Сохранены Open Sans, светлая шапка, жёлтая кнопка и оригинальные изображения Teaboom. Фото и покупка стоят рядом на широком экране, на телефоне название, фото и управление идут последовательно. Анимация ограничена сменой цвета кнопок. Проверены ширины 1440, 768 и 375 px, четыре набора цен и артикулов, переключение клавиатурой и нажатие кнопки. Горизонтального переполнения и ошибок консоли при проверке не обнаружено.

## Источники

Фото товара, логотип, категория и сведения о чае взяты с [карточки Teaboom](https://teaboom.ru/product/ananasovij-ulun). Они принадлежат соответствующим правообладателям и использованы для тестового задания по разрешённому в нём условию. Цены и артикулы соответствуют заданию, актуальные данные не запрашиваются.

Open Sans распространяется по SIL Open Font License; текст лицензии в `assets/fonts/OFL.txt`.
